# CS:GO / CS2 Armory 🔫

A responsive weapon skins marketplace UI built with vanilla HTML, CSS, and JavaScript. Showcases CS:GO/CS2 weapon skins in a clean, dark-themed product grid — inspired by real marketplace listings.

## Features
- Dynamic product cards generated via JavaScript (`Array.forEach`)
- Rarity-based color coding (Covert, Classified, Restricted)
- Responsive CSS Grid layout with hover animations
- Custom CSS variables for easy theming
- 20+ weapon skins with pricing and "Buy Now" interactions

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (DOM manipulation)

## Getting Started
1. Clone the repo
2. Open `index.html` in your browser (or use Live Server)
